# Hội Quán Thám Tử

Website tĩnh dành cho Hội Quán Thám Tử, sử dụng hai nhân vật chính Gà và Hiraku.

## Chạy trên máy

Mở trực tiếp `dist/index.html` bằng trình duyệt, hoặc chạy một web server tĩnh tại thư mục `dist`.

Ví dụ:

```bash
cd dist
python3 -m http.server 8080
```

Sau đó truy cập `http://localhost:8080`.

## Cấu trúc

- `dist/index.html`: nội dung website.
- `dist/assets/style.css`: giao diện và responsive.
- `dist/assets/app.js`: menu, bộ lọc và tương tác mở manh mối.
- `dist/assets/ga.png`: hình nhân vật Gà.
- `dist/assets/hiraku.png`: hình nhân vật Hiraku.

Không cần cài đặt package hoặc build source.
